Micro Star 离线地平线星图固件
============================

硬件：
- ESP32-C3
- 厂家 1.54 英寸 240x240 ST7789 屏幕
- 位置优先读取设备已保存的经纬度；未保存时使用纬度 31.771894、经度 117.198016

自动校时（已在本机安装）：
- Windows 登录后，Micro Star 自动校时监听器在后台隐藏运行。
- 每次拔下并重新连接设备 USB，监听器会自动识别 MICROSTAR 并发送电脑当前时间。
- 无需再手动运行 StarTimeSync.cmd。
- 自动校时日志位于：%LOCALAPPDATA%\MicroStar\StarTimeAutoSync.log

在其他 Windows 电脑上首次安装：
1. 双击 Install-StarTimeAutoSync.cmd。
2. 安装完成后，监听器立即启动，并在以后每次登录 Windows 时自动运行。
3. 如需取消自动启动，运行 Uninstall-StarTimeAutoSync.ps1。
4. StarTimeSync.cmd 保留为手动备用工具。

重要限制：
- 设备没有独立 RTC，完全断电后无法自行保存真实时间。
- 自动校时要求 USB 连接到已安装监听器并已登录的 Windows 电脑。
- 如果接普通充电头，设备无法从充电头获得时间。
- 不使用 Wi-Fi，也不需要互联网。

画面说明：
- 屏幕约 3/4 高度处为水平地平线，不显示穹顶或穹底网格。
- 屏幕左上角以双倍字号显示当前本地时间 HH:MM:SS，并为时间保留独立避让区域。
- 方位角从右向左递增：右侧 0/N、90/E、180/S、270/W、左侧 360/N。
- 显示太阳、月亮、火星、木星和土星；土星使用带椭圆环的专用符号。
- H≤0 的天体完全隐藏；0°到4°为平滑升起/落下过渡区，符号逐渐放大或缩小，标签分阶段出现。
- 天体穿越地平线时，符号周围会留出 2 像素深色间隔，并暂时隐藏对应的彩色短刻度，避免符号、地平线与刻度重合。
- 当太阳落到地平线下后，固定位置的装饰星点会随夜色逐渐增加；日出时反向减少，不会每帧随机闪烁。
- 天体名称与括号信息组成同一标签；M+1.3 等 M 数值为火星视星等，数值越小越亮。

固件文件：
- micro-star-full-4MB.bin：完整单文件固件，写入地址 0x0。
- bootloader.bin：地址 0x0。
- partitions.bin：地址 0x8000。
- boot_app0.bin：地址 0xe000。
- micro-star-firmware.bin：地址 0x10000。

恢复飞机雷达：
- 上一级 outputs 目录保留 micro-radar-adsb-working-full-flash-2026-07-28.bin。
- 该文件写入地址 0x0，大小 4MB。
